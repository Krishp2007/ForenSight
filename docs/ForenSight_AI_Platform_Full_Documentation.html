1. Executive Overview & Core Capabilities

ForenSight AI is a next-generation enterprise digital forensics and incident response (DFIR) platform. It provides automated evidence ingestion, multi-source log parsing, graph-based relationship correlation, machine-learning anomaly detection, and a natural language AI Copilot powered by Google Gemini and vector similarity search.

Core Mission
Transform raw, fragmented, multi-source forensic evidence into structured, searchable intelligence—enabling security teams to reconstruct incident timelines, track adversary movements, and generate court-ready investigation reports in minutes.

3. Evidence Ingestion & Forensic Parsing Pipeline

When an investigator uploads a file, it passes through an automated ingestion pipeline designed for evidentiary integrity and rapid processing:

  1. Upload & Chain of Custody: File is uploaded to MinIO object storage. The backend immediately computes its SHA-256 cryptographic checksum to preserve evidentiary proof of non-tampering.
  2. Parser Selection: MIME type and extension detection select the appropriate parser from backend/app/parsers/.
  3. Normalizing Event Structure: Raw log lines/records are converted into standardized ForensicEvent objects with normalized timestamps (UTC ISO-8601).
  4. Machine Learning Scoring: The feature matrix is evaluated by PyOD models to assign an anomaly score ($0.0 - 1.0$).
  5. Dual Ingestion (Graph & Vector): Extracted entities (IPs, Usernames, File Hashes) are merged into Neo4j graph relationships, while event descriptions are embedded into Qdrant vector space.

4. Machine Learning & Anomaly Detection Engine

ForenSight AI integrates **PyOD** (Python Outlier Detection) to detect hidden threat activity without needing labeled training data.

Outlier Detection Algorithm: HBOS

The primary model used is **Histogram-based Outlier Score (HBOS)**. HBOS evaluates multivariate distributions by constructing univariate histograms for each feature, calculating density scores in $O(N)$ operational time.

# Anomaly Scoring Pipeline (app/services/intelligence/anomaly.py)
from pyod.models.hbos import HBOS

def calculate_anomaly_scores(feature_matrix):
    model = HBOS(n_bins=15, contamination=0.05)
    model.fit(feature_matrix)
    raw_scores = model.decision_scores_
    normalized_scores = (raw_scores - raw_scores.min()) / (raw_scores.max() - raw_scores.min() + 1e-6)
    return normalized_scores

Rule-Based Heuristic Alerts

  • Brute Force Velocity: $\ge 10$ failed logon events (Event ID 4625) from the same IP within 60 seconds.
  • Log Erasure Alert: Audit log clearing (Event ID 1102) detected during active investigation.
  • Unusual Admin Activity: Special privileges assigned (Event ID 4672) to an account outside normal working hours.
  • High-Entropy DNS Query: DNS TXT query domain length $> 45$ characters (indicating potential DNS tunneling).

5. Knowledge Graph & Cross-Case Vector Intelligence

Neo4j Entity Graph Topology

ForenSight AI constructs a connected entity graph to reveal hidden relationships across multiple evidence files.

    -[:LOGGED_INTO {timestamp: "2026-08-04T01:00:00Z"}]-> (Host:Workstation {hostname: "FINANCE-PC"})
    -[:GENERATED]-> (Event:ForensicEvent {event_id: 4624, severity: "HIGH"})
    -[:COMMUNICATED_WITH]-> (IP:IPAddress {address: "198.51.100.45"})
    -[:RESOLVED_TO]-> (Domain:DomainName {name: "malicious-c2-server.com"})

Qdrant Vector Store & IoC Correlation

Events and evidence descriptions are mapped into a 384-dimensional vector space using sentence-transformers/all-MiniLM-L6-v2. When analyzing a new case, Qdrant executes cosine similarity queries across all historical cases to surface matching threat patterns and shared Indicators of Compromise (IoCs).

10. Security, RBAC & Multi-Tenant Isolation

ForenSight AI implements strict defense-in-depth security mechanisms across all API layers:

  • Authentication: Passwords are hashed using bcrypt (cost factor 12). API access uses OAuth2 Bearer Tokens (JWT with HS256 algorithm).
  • Role-Based Access Control (RBAC):
    • Admin: Full organizational access, user role assignment, audit log monitoring.
    • Investigator: Case creation, evidence uploading, AI Copilot interaction, report export.
    • Analyst: Evidence viewing, timeline analysis, event annotation.
    • Viewer: Read-only access to published reports and executive dashboards.
  • Multi-Tenant Isolation: Every database query (MongoDB, Neo4j, Qdrant) enforces mandatory organization_id scoping, ensuring total data segregation between organizations.
