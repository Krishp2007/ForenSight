ForenSight AI — Processing Pipeline Diagram

End-to-End Forensic Evidence Ingestion, Graph Lineage Sync & AI Vector Indexing Flow

01

Evidence Upload & SHA-256 Hashing FastAPI · MinIO S3

Investigator uploads single forensic file. Backend computes SHA-256 hash for deduplication and streams binary object directly into MinIO S3 storage bucket.

🔒 SHA-256 Hashing 📦 MinIO Object Storage 📄 Evidence Document in MongoDB
02

Format Detection & Parser Execution Thread Executor · Scapy · DictReader

File type is inferred (Magic Bytes). Parser extracts structured Subject-Action-Object event records in parallel thread workers without blocking main loop.

🔍 Type Auto-Inference 🌐 Scapy (.pcap/.pcapng) 🗄️ SQLite (.sqlite) 📊 CSV / JSON / TXT
03

MongoDB Bulk Database Insert MongoDB Async Driver

Events are enriched with org_id, case_id, evidence_id, and written in chunked bulk operations (500 records/batch). Status set to PARSED.

⚡ Chunked Bulk Creation ⏱️ Timer Stops (PARSED) 🛡️ SAO Normalization
04

Neo4j Graph Synchronization & Cypher Analytics Neo4j Async Driver

EntityRelationshipExtractor maps entities into graph nodes (Process, Domain, IP, File) and edges (SPAWNED, CONNECTED_TO, MODIFIED). Cypher correlation rules execute.

🌳 Process Lineage Trees 🕸️ LOLBin Detection 🔑 Registry Persistence
05

ML Anomaly Scoring & FAISS Vector Indexing Isolation Forest · MiniLM · FAISS

Isolation Forest calculates anomaly scores for events. Unique event sentences are embedded using MiniLM transformer model and stored in local FAISS vector search index.

🤖 ML Anomaly Scores 🧠 SentenceTransformer 🔍 FAISS Cosine Index
