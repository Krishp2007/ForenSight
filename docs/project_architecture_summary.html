ForenSight AI — Full System Architecture & File-by-File Guide

Event-Driven Digital Forensics & AI Copilot Analysis Platform

ForenSight/ ├── backend/ # FastAPI Backend API, AI Reasoning, Parsers & Graph Engine ├── frontend/ # React (Vite) Cyberpunk Forensic Investigator Interface ├── docs/ # Full Platform & Architecture Documentation ├── Dockerfile # Multi-stage container setup └── docker-compose.yml # Service Orchestration (FastAPI, MongoDB, Neo4j, Redis, MinIO)

1. Backend Application Core & API Routes

Core backend/app/main.py

Application entry point. Initializes MongoDB, Neo4j, Redis, MinIO lifecycle handlers, configures GZip/CORS middleware, runs startup evidence crash recovery, and mounts API routers.

Core backend/app/config.py

Central Settings using Pydantic BaseSettings for loading environment configuration (`GROQ_API_KEY`, `MONGODB_URI`, `NEO4J_URI`, `MINIO_*`, `JWT_SECRET`).

API backend/app/api/evidence.py

Handles SHA-256 evidence hashing, MinIO S3 uploading, background processing pipeline triggering, re-processing, and cascading deletion (S3, Mongo, Neo4j, FAISS).

API backend/app/api/chat.py

AI Copilot endpoints. Supports both non-streaming POST queries and real-time Server-Sent Events (SSE) token streaming (`GET /copilot/stream`).

API backend/app/api/graph.py

Knowledge Graph API. Serves nodes & relationships formatted for Cytoscape.js canvas rendering, shortest path lookups, and neighborhood expansion.

API backend/app/api/events.py

Forensic timeline API. Queries MongoDB events by case with severity & event_type filtering and safe model mapping fallbacks.

API backend/app/api/correlations.py

Graph Correlation Engine route. Returns detected attack chains, LOLBin executions, registry persistence modifications, and threat severity scores.

API backend/app/api/cases.py

Case management endpoint (create case, list by organization, status update, case overview metrics).

API backend/app/api/auth.py

User authentication & authorization (login, user registration, JWT token generation, password resets).

2. Evidence Ingestion & Parsers

Parser parsers/__init__.py

Factory loader `get_parser(file_type)` returning the appropriate parser instance (with lazy Scapy loading for `.pcap`).

Parser parsers/pcap_parser.py

Parses binary `.pcap`/`.pcapng` network packet captures using Scapy into network IP socket & DNS event records.

Parser parsers/browser_parser.py

Ingests Chrome/Edge SQLite databases (`History`, `Downloads`, `Logins`) and extracts domain visits and credentials.

Parser parsers/csv_parser.py

Smart DictReader CSV parser with automatic column alias detection (`timestamp`, `subject`, `action`, `object`, `IP`, `PID`).

Parser parsers/json_parser.py

Ingests structured JSON event arrays and normalizes schema fields for database writing.

Parser parsers/extractor.py

`EntityRelationshipExtractor` that extracts Neo4j nodes (`Process`, `Domain`, `IP`, `File`) and edges (`SPAWNED`, `CONNECTED_TO`) from parsed events.

3. AI Copilot, RAG Pipeline & Analytics

AI services/ai/copilot.py

Main Copilot orchestrator. Manages RAG context building, Groq API invocations, token streaming, and fallback execution.

AI services/copilot/groq_provider.py

Production Groq LLM client (`llama-3.3-70b-versatile`). Implements exponential retry backoff, timeout handling, and refusal detection.

AI services/copilot/query_router.py

Classifier & fast-path executor for 12 query types (file sizes, case counts, graph attack chains, greetings, etc.).

AI services/copilot/report_generator.py

Local deterministic fallback engine. Builds structured Markdown DFIR reports when external LLMs are unavailable.

AI services/ai/vector_store.py

FAISS vector store engine. Deduplicates event sentences, encodes via `all-MiniLM-L6-v2`, and executes cosine similarity searches.

AI services/graph/graph_correlation.py

Cypher correlation rules (detects LOLBin binaries, autostart registry modifications, C2 domain lookups, and process execution chains).
